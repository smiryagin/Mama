# Рабочие материалы для рассказов

В этой папке собираются подборки фрагментов, планы, черновики и тексты рассказов, над которыми идёт работа.

Папки `Stories` и `Mama-Latest-Markdown` используются только как исходные материалы. Их тексты не редактируются. При работе нужные фрагменты копируются сюда, а все сокращения, перестановки и литературная правка выполняются только в этой папке.

Папка `Stories Done` содержит уже опубликованные рассказы и используется для проверки возможных повторов.
